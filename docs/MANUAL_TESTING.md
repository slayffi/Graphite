# Чек-лист ручного тестирования

Для проверки нужны: ПК с Windows 10/11 (установщик `.exe` или `.msi` из CI-артефакта `graphite-windows`), телефон на Android 8+ (APK из `graphite-android`), обе машины в одной сети Wi-Fi. Легальные тестовые торренты: образы Ubuntu / Debian, открытые фильмы Blender (Sintel, Big Buck Bunny).

Отмечайте `[x]`; найденные проблемы записывайте с шагами и строкой из журнала событий (Настройки → Журнал событий).

## 1. Установка и первый запуск

- [ ] Windows: `.exe` (и `.msi`) ставится без прав администратора, в «Пуск» есть ярлык, иконка — тёмный кристалл.
- [ ] Windows: установка `.exe` поверх установленной из `.msi` той же версии не создаёт вторую копию в «Приложениях».
- [ ] Windows: при повторной установке новой версии старая обновляется, загрузки и настройки сохраняются.
- [ ] Android: APK ставится, иконка кристалла на чёрном (в т. ч. тематическая монохромная на Android 13+).
- [ ] Android 13+: запрос разрешения на уведомления при первом запуске.
- [ ] Заставка с кристаллом не дольше секунды, затем пустое состояние «Добавьте первую загрузку».
- [ ] Язык интерфейса следует системе (русский / английский), числа и единицы локализованы («МБ/с» / «MB/s»).

## 2. Добавление

- [ ] Кнопка «+» → magnet из буфера обмена подставляется сам.
- [ ] Предпросмотр magnet: «Получение списка файлов…» → дерево файлов; отмена выбора, приоритеты, раскрытие папок.
- [ ] «Начать без предпросмотра» добавляет сразу.
- [ ] `.torrent` через диалог, перетаскиванием в окно (Windows), двойным щелчком по файлу в Проводнике.
- [ ] Ссылка `magnet:` из браузера открывает Graphite (Windows и Android); если Graphite уже запущен — открывается в том же окне.
- [ ] Android: «Поделиться» → Graphite из браузера (текст со ссылкой) и из файлового менеджера (`.torrent`).
- [ ] Android: сканирование QR с magnet-ссылкой.
- [ ] Индикатор свободного места; при нехватке — предупреждение, а добавление выдаёт «Недостаточно места на диске» с советом.
- [ ] Битая ссылка / испорченный `.torrent` → понятное сообщение и совет, приложение не падает.
- [ ] Повторное добавление того же торрента → «Эта раздача уже добавлена» с советом.
- [ ] Выбор другой папки; на Android — папка через системный выбор (SAF), после завершения файлы оказываются в ней.
- [ ] Недоступная папка (отключённый USB-диск, папка только для чтения) → «Папка недоступна» сразу при добавлении.

## 3. Список и управление

- [ ] Карточка: длинное имя обрезается посередине, видны скорость, размер, ETA, прогресс.
- [ ] Пауза / продолжение из карточки, деталей, контекстного меню (ПКМ на Windows), свайпа (Android).
- [ ] Удаление: окно подтверждения; «удалить с файлами» реально удаляет файлы, без — оставляет.
- [ ] Выделение долгим нажатием → массовые пауза / продолжение / удаление; Esc и Delete на Windows.
- [ ] Очередь: режим перетаскивания меняет порядок, порядок сохраняется после перезапуска.
- [ ] Фильтры «Все / Активные / Пауза / Готово» со счётчиками, поиск, сортировки.
- [ ] Повторная проверка хэша: состояние «Проверка», затем прежний прогресс.
- [ ] Категории и теги: назначить, отфильтровать.
- [ ] Перезапуск приложения посреди загрузки: всё продолжается с того же места (данные возобновления).

## 4. Скорость и сеть

- [ ] Профиль «Турбо» по умолчанию; на популярном торренте скорость упирается в канал.
- [ ] Переключение профилей «Баланс» / «Экономия» снижает число соединений (Подробности → Пиры).
- [ ] Порт: после первого запуска выбран случайный; статус порта «открыт» при работающем UPnP на роутере.
- [ ] В подробностях на вкладке «Трекеры» есть публичные трекеры из списка; список обновляется (Настройки → Трекеры).
- [ ] Лимит скачивания в КБ/с работает и снимается значением 0.
- [ ] Отключение сети → понятная ошибка; после восстановления загрузка продолжается сама.

## 5. Нулевая отдача

- [ ] По умолчанию включена; в шапке списка «Отдано: 0 Б ✓».
- [ ] После полной загрузки популярного торрента «Отдано (данные)» в подробностях = 0 Б.
- [ ] На 100 % торрент сразу переходит в «Готово» и не раздаёт (в Диспетчере задач / мониторе ресурсов исходящий трафик Graphite около нуля).
- [ ] При выключенной нулевой отдаче раздача снова возможна (для приватных трекеров).

## 6. Стриминг и плеер

- [ ] У видеофайла в подробностях (вкладка «Файлы») кнопка «Воспроизвести»; воспроизведение начинается до окончания загрузки.
- [ ] Перемотка вперёд в ещё не скачанную часть: короткая буферизация, затем воспроизведение.
- [ ] Включается последовательная загрузка; после закрытия плеера её можно выключить.
- [ ] Windows: плеер работает из MSI без установленного VLC.
- [ ] «Открыть во внешнем плеере» передаёт ссылку на поток.

## 7. Удалённое управление (телефон → ПК)

- [ ] ПК: Настройки → Удалённое управление → включить, виден QR-код.
- [ ] Телефон: Настройки → Удалённое управление → «Сканировать QR-код» → «Подключено», видно имя ПК.
- [ ] С телефона видны загрузки ПК со скоростями; пауза, продолжение, удаление, добавление magnet выполняются на ПК.
- [ ] После перезапуска телефона подключение восстанавливается само.
- [ ] «Новый ключ (отвязать телефоны)» на ПК → телефон больше не может управлять, пока не отсканирует новый QR.
- [ ] Выключение «Управлять <имя ПК>» на телефоне возвращает локальные загрузки телефона; «Забыть этот ПК» удаляет сопряжение.
- [ ] Брандмауэр Windows: при первом включении появляется запрос доступа для частной сети.

## 8. Автоматизация

- [ ] Планировщик: правило «пауза с … до …» на ближайшие минуты — загрузки встают на паузу и продолжаются после окончания окна. Правило через полночь работает.
- [ ] Правило лимита скорости и правило смены профиля.
- [ ] RSS: добавить ленту, правило с включающими и исключающими словами; новые выпуски добавляются сами, старые при добавлении ленты — нет.
- [ ] Наблюдаемая папка: положить `.torrent` → добавлен, файл переименован в `.added` (или удалён по настройке); битый файл → `.invalid`.
- [ ] Действия после завершения: уведомление, звук; «сон» и «выключение» на Windows (проверять с сохранёнными документами!).

## 9. Приватность и безопасность

- [ ] Шифрование протокола «требовать» — пиры подключаются только с шифрованием.
- [ ] SOCKS5-прокси: трафик идёт через прокси (проверить на прокси-сервере).
- [ ] Привязка к интерфейсу VPN: при отключении VPN загрузки останавливаются (kill switch) и возобновляются после подключения.
- [ ] IP-фильтр: загрузка файла `.dat` / `.p2p`, число диапазонов в журнале.
- [ ] Экспорт настроек не содержит ключа удалённого управления; импорт на другом устройстве восстанавливает настройки и загрузки.

## 10. Android

- [ ] Во время загрузки — постоянное уведомление с прогрессом и кнопками «Пауза всех» / «Продолжить» / «Выход».
- [ ] Загрузка продолжается при выключенном экране и свёрнутом приложении (проверить 30+ минут).
- [ ] «Только по Wi-Fi»: при переходе на мобильную сеть — пауза с причиной, при возврате на Wi-Fi — продолжение.
- [ ] «Только при зарядке» и «Пауза при низком заряде» (порог в настройках).
- [ ] Виджет на рабочем столе: скорость, число загрузок, кнопка пауза/продолжить.
- [ ] Плитка в быстрых настройках: скорость в подписи, нажатие ставит на паузу / продолжает.
- [ ] Доступ ко всем файлам (по желанию): после выдачи файлы пишутся сразу в выбранную папку, без копирования.
- [ ] Без этого доступа: в окне добавления под папкой есть подсказка с кнопкой «Разрешить»; загрузка идёт в память приложения, после 100 % карточка показывает «Перемещение» с прогрессом, затем файлы лежат в выбранной папке, а во внутренней памяти их нет.
- [ ] Перенос прерван (приложение закрыто во время «Перемещения») — после запуска он повторяется; уже существующие в папке файлы с тем же именем не затираются.
- [ ] Наблюдаемая папка, выбранная через системный выбор папки: `.torrent` добавляется в течение ~30 с и переименовывается в `.added`, повторно не добавляется.
- [ ] Экономия заряда: раздача без сидов (0 Б/с) дольше 10 минут — в «Настройки → Батарея» Android приложение не держит устройство активным постоянно; когда появляется сид, загрузка продолжается (при выключенном экране — в течение ~15 минут).
- [ ] Пауза вручную («Пауза всех») — уведомление исчезает через ~20 с; пауза по правилу (нет Wi-Fi) — уведомление остаётся и показывает причину.
- [ ] Открытие magnet-ссылки из браузера при уже запущенном приложении — окно добавления появляется сразу, без заставки.
- [ ] Поворот экрана, планшет / раскладной телефон: боковая панель и две колонки на широком экране.
- [ ] TalkBack читает карточки («имя, состояние, процент») и кнопки.

## 11. Windows

- [ ] Сворачивание в трей, меню трея (открыть, добавить, пауза всех, выход), уведомления из трея.
- [ ] Автозапуск со свёрнутым окном после перезагрузки.
- [ ] Открытие magnet-ссылок (переключатель в настройках) включается и выключается; `.torrent` связывается установщиком.
- [ ] Мини-окно поверх всех окон: скорость и прогресс, перетаскивается.
- [ ] Горячие клавиши: Ctrl+Alt+P (пауза всех), Ctrl+Alt+R (продолжить), Ctrl+Alt+G (показать окно), Ctrl+Alt+M (мини-окно); Ctrl+O, Ctrl+V в окне.
- [ ] Прогресс на кнопке в панели задач.
- [ ] Тёмный заголовок окна, масштаб 125–200 % без размытия.

## 12. Внешний вид

- [ ] Без теней; контрастность текста достаточная; AMOLED-режим даёт чистый чёрный фон.
- [ ] Режим уменьшения анимаций отключает лишнее движение.
- [ ] Все тач-цели не меньше 48 dp; клавиатурная навигация Tab / Enter на Windows.
