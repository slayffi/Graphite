Первый выпуск Graphite — быстрого торрент-клиента для Windows и Android без рекламы, аналитики и сбора данных.

## Главное

- **Нулевая отдача по умолчанию.** Данные другим пирам не отдаются, после 100 % раздача не начинается. Проверено тестом на трёх настоящих сессиях libtorrent. Для приватных трекеров с рейтингом её нужно выключить в настройках.
- **Добавление:** `.torrent`, magnet-ссылки, QR-код и «Поделиться» (Android), наблюдаемая папка, RSS с фильтрами. Перед загрузкой — выбор файлов, приоритетов и папки, проверка свободного места.
- **Скорость:** DHT, PEX, LSD, uTP, UPnP / NAT-PMP, веб-сиды, IPv6, автообновляемый список трекеров. Профили «Турбо», «Баланс», «Экономия».
- **Стриминг** со встроенным плеером: смотреть можно, пока файл качается.
- **Управление ПК с телефона** в локальной сети: пара по QR-коду, шифрование AES-256-GCM.
- **Приватность:** шифрование протокола, SOCKS5 / HTTP-прокси, привязка к интерфейсу VPN с kill switch, IP-фильтр.
- **Автоматизация:** планировщик, действия после завершения, экспорт и импорт настроек и загрузок.
- **Android:** загрузка в фоне с уведомлением, только Wi-Fi / только при зарядке / пауза при низком заряде, виджет, плитка быстрых настроек, выбор любой папки. Телефон не держится «проснувшимся», пока данных нет.
- **Windows:** установщик MSI, трей, автозапуск, ассоциации `.torrent` и `magnet:`, мини-окно, горячие клавиши, прогресс на панели задач.

## Установка

**Android 8.0 и новее.** Почти всем подходит `android-arm64-v8a`. Для старых 32-битных телефонов — `armeabi-v7a`, для эмуляторов и Chromebook — `x86_64`. Если не уверены — `universal` (он больше, но подходит всем). Android спросит разрешение на установку из этого источника.

**Windows 10 / 11 (64-бит).** Запустите `.msi`. Установщик не подписан сертификатом издателя, поэтому SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае». Плеер (libVLC) уже внутри.

## Что стоит знать

- Версии на телефоне и ПК должны совпадать, иначе удалённое управление не подключится.
- Без разрешения «Доступ ко всем файлам» Android не даёт писать в выбранную папку напрямую: загрузка идёт в память приложения и переносится в папку после завершения. На это время нужно место под файлы дважды.
- При спящем телефоне правило планировщика может сработать с опозданием до 15 минут — так экономится заряд.
- macOS и Linux не выпускаются: код собирается, но не проверялся.
