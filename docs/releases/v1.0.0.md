The first release of Graphite — a fast torrent client for Windows and Android with no ads, analytics or data collection.

## Highlights

- **Zero upload by default.** No data is sent to other peers and nothing is seeded after completion. This is verified by a test with three real libtorrent sessions. Private trackers that require a ratio need it switched off in the settings.
- **Adding:** `.torrent` files, magnet links, QR codes and Share (Android), a watched folder, RSS with filters. Before a download starts you choose the files, their priorities and the folder, and free space is checked.
- **Speed:** DHT, PEX, LSD, uTP, UPnP / NAT-PMP, web seeds, IPv6, an auto-updated tracker list. Turbo, Balanced and Economy profiles.
- **Streaming** with a built-in player: watch while the file is still downloading.
- **Control your PC from your phone** on the local network: pair with a QR code, encrypted with AES-256-GCM.
- **Privacy:** protocol encryption, SOCKS5 / HTTP proxy, binding to a VPN interface with a kill switch, IP filter.
- **Automation:** scheduler, actions on completion, export and import of settings and downloads.
- **Android:** background downloads with a notification, Wi-Fi only / charging only / pause on low battery, widget, Quick Settings tile, any folder you choose. The phone is not kept awake while no data is flowing.
- **Windows:** installer, tray icon, autostart, `.torrent` and `magnet:` associations, mini window, hotkeys, taskbar progress.

## Install

**Android 8.0 or newer.** `android-arm64-v8a` fits almost every phone. `armeabi-v7a` is for old 32-bit devices, `x86_64` for emulators and Chromebooks. If unsure, take `universal` — it is larger but works everywhere. Android will ask you to allow installation from this source.

**Windows 10 / 11 (64-bit).** Run the `.exe`. The installer is not signed with a publisher certificate, so SmartScreen may show a warning: *More info* → *Run anyway*. The player (libVLC) is included. The `.msi` is the same installer in another format, handy for silent deployment (`msiexec /i … /qn`); install only one of the two.

## Good to know

- The phone and the PC must run the same version, otherwise remote control will not connect.
- Without the "All files access" permission Android does not let an app write straight into the folder you chose: the download goes to the app's own storage and is moved to your folder when it completes. For that moment the files need their space twice.
- On a sleeping phone a scheduler rule may fire up to 15 minutes late; this is how battery is saved.
- Turbo, the default profile, takes the whole connection. If the rest of your network slows down, set a download limit or switch to Balanced.
- macOS and Linux are not shipped: the code builds there but has not been tested.
